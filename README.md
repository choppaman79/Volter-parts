# Volter-parts 更新手順（部品手入力・緊急対応・記録編集）

今回は index.html / data.js / app.js / style.css の4ファイルを更新しています
（firebase-sync.js は前回のままで変更ありません）。

## 追加・変更した機能

### ① 部品台帳への手入力追加
「部品台帳」画面右上に「＋ 部品を追加」ボタンを追加しました。
部品番号・部品名（必須）、分類、仕様、資料ページ、備考を入力して追加できます。
追加した部品には「✎ 手入力追加」の表示が付き、カード内から削除もできます
（在庫・点検記録の部品検索にもすぐに反映されます）。

### ② 点検項目に「緊急対応（随時）」を追加
「点検スケジュール」の一番下に、⚡「緊急対応（随時）」というカードを追加しました。
運転時間の周期に関係なく、突発的な故障・不具合対応をいつでも記録できます。
このカードにはチェックリストがなく、備考欄に対応内容（原因・応急処置・恒久対策など）を
自由に書く形になっています。記録一覧では「緊急対応」のバッジで区別されます。

### ③ 点検記録の編集
「点検記録一覧」の各記録に「編集」ボタンを追加しました。押すと保存時と同じ画面が開き、
実施日・チェック項目・使用部品・備考を後から修正して上書き保存できます
（削除して登録し直す必要はありません）。

## アップロード方法
GitHubのリポジトリで、4ファイル（index.html / data.js / app.js / style.css）を
このフォルダの内容に置き換えてCommitしてください。firebase-sync.jsは変更していないので
そのままで大丈夫です。
