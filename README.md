# Volter-parts 更新手順（点検記録機能の追加）

4ファイルすべて（index.html / data.js / app.js / style.css）を更新しています。

## 追加した機能

### 1. 点検項目チェックリスト
各点検周期（1週間〜6年の8ステージ）に、取扱説明書に基づく具体的な点検項目を追加しました。

### 2. 点検記録
「点検スケジュール」の各カードに「📝 点検を記録」ボタンを追加。押すと以下を記録できます。
- 実施日
- 点検項目ごとのチェック（実施漏れが分かる）
- 交換・使用した部品（部品名や品番で検索して追加、数量も指定可）
- 備考欄（自由記述）

### 3. 点検記録一覧
「点検」画面右上、またはメニューから「点検記録一覧」を開くと、過去の記録を日付順に確認できます。各記録には完了項目数（例：6/7項目完了）、使用部品、備考が表示され、削除も可能です。

## 注意
点検記録データもブラウザのlocalStorageに保存されます（在庫データと同様、端末ごとに別）。定期的に「設定」画面の「バックアップ(JSON)」で保存することをおすすめします。
