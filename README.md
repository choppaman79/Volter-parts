# Volter-parts 更新手順（デザイン刷新＋定期交換品追加）

4ファイルすべて（index.html / data.js / app.js / style.css）を更新しています。

## 変更内容

### 1. 定期交換品を10件→24件に拡充
取扱説明書§6.2・§7に基づき、以下を追加しました。
- 3ヶ月点検(1800h)関連：フィルターカートリッジ、セーフティーフィルター、耐火セメント、耐火断熱材、
  抗焼き付きグリース、エアノズル、ロータリーバルブ、フィーディングチューブ、インナー/アウターセンターチューブ
- 1年点検(7200h)：エアノズル上部ベアリング
- 3年点検(21600h)：シリンダーヘッド
- 6年点検(43200h)：ガスエンジン本体（オーバーホール）
- 長期(78000h)：冷却水循環路凍結防止剤

### 2. 数量ロジックの修正（前回分の反映）
エンジンオイル/フィルター/オイルクリーナー、スパークプラグ関連の「1回あたり使用数」を実際の値に修正済み。

### 3. デザイン刷新
Volterのロゴカラー（ライムグリーン）を基調にした、制御パネル／HMI風のダークテーマに変更しました。
- 部品番号や運転時間は等幅フォントで「機器の読み取り値」のような見た目に
- 点検スケジュール画面の各カードに、運転時間に対する進捗を示すゲージバーを追加
- 背景にうっすらブループリント風のグリッド線

### 4. 不具合修正
「点検スケジュール」画面末尾に「出典」情報が1件の点検項目として誤混入し、NaN回/年と表示される不具合を修正（出典情報は「設定」画面下部に正しく表示されるよう移動）。
